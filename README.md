# Targi

Targi is an Armenian-first Expo React Native app for tracking recovery progress from difficult habits such as smoking, alcohol, gambling, social media, and other addictions.

## Features

- Multiple recovery journeys
- Daily check-ins with supportive Armenian copy
- Milestones and current progress tracking
- Local reminder notifications
- Health improvement timeline
- Money-saved estimate
- Progress detail pages
- Local-only storage with AsyncStorage

## Tech Stack

- Expo
- React Native
- TypeScript
- React Navigation
- AsyncStorage
- Expo Notifications

## Getting Started

Install dependencies:

```bash
npm install
```

Start Expo:

```bash
npm start
```

Run on iOS:

```bash
npm run ios
```

Run TypeScript checks:

```bash
npm run check
```

Format code:

```bash
npm run format
```

## Privacy

Targi does not require an account and currently stores progress locally on the user's device. See [Targi-Privacy-Policy.html](./Targi-Privacy-Policy.html).
